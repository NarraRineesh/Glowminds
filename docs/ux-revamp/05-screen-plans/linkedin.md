# LinkedIn Optimization Center

## UX Goals
Guided Sync → Audit → Rewrite. Extension is step 1, not a footnote.

## Hierarchy
Stepper (1 Import 2 Audit 3 Rewrite) · Score gauge · Strength · Improvements · Keyword tags · Rewrite cards with Copy.

## User Flow
Install/open extension → Import → Run audit (credit) → Copy rewrite → Open LinkedIn.

## Desktop
Left main (steps+fields+checklist) / right rail (score+rewrites).

## Tablet/Mobile
Vertical stepper; rewrites accordion under audit.
