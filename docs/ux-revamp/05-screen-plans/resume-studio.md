# Resume Studio

## UX Goals
Craft, score, and manage resumes as one workspace. ATS is first-class. Templates live inside Builder.

## Screens
Studio home · Builder · ATS Report · Library

## Hierarchy
Studio: Tabs (Library | ATS | Builder) + resume switcher + primary “Improve with AI”.
ATS: Large score · breakdown bars · suggestion list with Apply → Builder.
Builder: Mini-bar (Back | Saved | ATS) + embed canvas.
Library: Grid of resumes with score badges + actions.

## User Flow
Pick resume → ATS → act on suggestion → Builder → save → optional Vault attach / Public download.

## Desktop
Builder: full canvas under mini-bar. ATS: 8 score+bars / 4 suggestions. Library: 3-col cards.

## Tablet
ATS stacks suggestions under gauge. Library 2-col.

## Mobile
Tabs as segmented control; Builder full screen; Library list.
