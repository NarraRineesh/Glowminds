# System surfaces

## Settings
Goals: Account, privacy (public), preferences without competing with Profile.
Hierarchy: Section list · Panel · Destructive zone.
Desktop: 3+9 split. Mobile: section list then panel.

## Notification Center
Goals: Actionable alerts with deep links.
Hierarchy: Unread filter · List · Mark all · Item → route.
Shell: bell popover; full page optional.

## Command Palette
Goals: Navigate + run AI actions.
Hierarchy: Input · Groups (Navigate / Actions / Recent).
Modal centered; mobile full-screen sheet.

## LinkedIn Assist (extension)
Goals: Capture fields → import.
Hierarchy: Status · Field checklist · Copy JSON · Open GlowMinds Sync.
Popup 320px branded.

## Career Timeline
Goals: Chronology of career events (applies, mocks, syncs, scores).
Hierarchy: Filter · Vertical timeline · Jump to source.
Embed on Dashboard; expandable on Insights.
