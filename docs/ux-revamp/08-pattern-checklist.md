# Pattern checklist — Design Lab

## Headers (updated)

Keep headers **quiet** — product title + optional short subtitle + at most one primary action.

**Do not** put on every screen:
- Uppercase “workspace identity” eyebrows (Career Command Center, etc.)
- A permanent **Next** coaching chip
- Twin AI + secondary CTAs that look identical on every page

| Question | Where it lives |
|----------|----------------|
| Where am I? | Sidebar highlight + simple page title |
| What can I do? | Contextual toolbar / primary in the workspace body |
| What’s next? | **Only where it earns its place** — Dashboard Focus card, action plan, Apply Kit — not a header chip |

## SplitRail

Main content + optional insight/AI rail. Rail is optional on simple screens.

## Guided flows

Stepper only for multi-step workflows (LinkedIn Import → Audit → Rewrite).
