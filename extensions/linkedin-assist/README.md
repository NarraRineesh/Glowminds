# Glowminds LinkedIn Assist (Chrome MV3)

1. Open Chrome → Extensions → Enable Developer mode
2. Load unpacked → select this `extensions/linkedin-assist` folder
3. Open your LinkedIn profile (`linkedin.com/in/...`)
4. Click the extension → **Copy profile JSON**
5. In Glowminds → **LinkedIn Sync** → **Import from extension**

No OAuth. Extraction is user-initiated only.
